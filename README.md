# 사활 노트

바둑 사활 문제를 입력하고, 직접 풀고, 스스로 채점하는 웹앱입니다. 빌드나 설치가 필요 없습니다.

## 실행
```bash
npm start        # 또는 node server.js  (Node.js만 있으면 되고, 설치할 패키지는 없음)
```
브라우저에서 http://127.0.0.1:4848 을 엽니다. 포트를 바꾸려면 `PORT=5000 npm start`로 실행합니다.

서버 없이 `index.html`을 바로 열어도 동작하지만, 그때는 기록이 브라우저에만 저장됩니다.

## 흐름
1. **새 문제 입력**: 흑/백/지우개로 배치하고 선수(흑선/백선)를 고른 뒤 저장합니다.
2. **풀기**: 흑과 백이 번갈아 놓이고 돌 위에 수순 번호가 붙습니다. 따내기, 자충수, 패 규칙이 적용됩니다. 패스는 없고, ‘뒤로가기’(또는 `←` 키)로 마지막 수를 하나씩 되돌릴 수 있습니다.
3. **채점**: 정답, 오답, 보류 중에서 고르고 메모를 남깁니다.
4. **다시 열기**: 문제를 누르면 배치가 보이고, ‘이전에 입력한 답 보기’로 지난 풀이를 한 수씩 넘겨 볼 수 있습니다.

## 저장
- 서버로 열면 문제 하나가 파일 하나로 `data/problems/<id>.json`에 저장됩니다. 커밋해 두면 기록이 git에 남고, push하면 다른 기기에서도 그대로 받아 쓸 수 있습니다.
- 오른쪽 위 표시로 지금 어디에 저장되는지 알 수 있습니다: ‘레포에 저장’ 또는 ‘브라우저에 저장’.
- 예전에 브라우저에 저장한 기록이 있으면, 목록 화면의 ‘브라우저 기록 N개를 레포로 옮기기’ 버튼으로 옮길 수 있습니다.
- ‘내보내기’와 ‘불러오기’(JSON 파일)도 그대로 쓸 수 있습니다.

## 단축키
- 입력 화면: `B` 흑, `W` 백, `E` 지우개 (한글 입력 상태의 `ㅠ`/`ㅈ`/`ㄷ`도 동작). 우클릭이나 Shift+클릭으로 반대색을 놓습니다.
- 답 보기 화면: `←`/`→`로 수순 이동, `Home`/`End`로 처음과 끝.
